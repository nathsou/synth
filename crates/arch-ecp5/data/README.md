# ECP5 data

`base/<device>.config`: the configuration of an empty design on each device
(settings the vendor tools always apply, such as the transceiver blocks'
interface ties), in Project Trellis' textual format. Generated by
`tools/ecp5_base_configs.py` from nextpnr's `ecp5/baseconfigs.cc`

notice appear in all copies."). The LFE5U-12F uses the LFE5U-25F's.
