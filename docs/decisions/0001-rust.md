# 0001: Implementation language: Rust

Status: Accepted

## Context

The toolchain handles very large graphs (tens of millions of routing nodes on
Artix-7), needs heavy parallelism in placement and routing, must produce
deterministic output, and should ship as a single self-contained binary for
macOS and Linux.

## Decision

Rust, stable toolchain, edition 2024. The minimum supported Rust version is
pinned in the workspace manifest.

## Consequences

- Memory safety and data-race freedom on large mutable graphs, with C++-level
  performance.
- Graphs use arenas with typed `u32` indices (`synth-core::IndexVec`) instead of
  pointers, which also keeps them compact and deterministic to iterate.
- Compile times are managed by splitting the workspace into crates along stable
  interfaces.
- A WASM build (browser playground) stays possible.
